Candle 2DFX in GTA III

Lesson 2. Mission: put a candle light (corona, point light, ground shadow) on a diner prop. Follows Lesson 1.

1. Where GTA III Reads 2DFX

The panel in your screenshot (Type: 2DFX, Effect: Light) is DragonFF's editor for the binary 2d Effect section embedded in a DFF. DragonFF's source reads and writes that section as one struct holding color, corona, shadow, and flag fields (DragonFF, gtaLib/dff.py, class Light2dfx). The GTAMods wiki documents that section for versions 3.6.0.3 and higher. San Andreas uses it for effects that earlier games kept in IDE files (2d Effect (RW Section)). GTA III and Vice City define lights in a text 2dfx section of an IDE file instead (2DFX (IDE Section)).

2. Does the Shadow Section Work in GTA III?

Shadows exist in GTA III, and you set them in the IDE file.

Do not rely on this panel for them. Its Shadow section is a San Andreas layout, and no source documents GTA III reading it.

4. Try It: Build a Candle Line

The output follows the column order on the 2DFX IDE wiki page. The corona and shadow names (coronastar, shad_exp) are the wiki's typical values. To list the names in particle.txd, open the file in RW Analyze and press F4 (Tools, Texture List). Its ReadMe says it was tested on GTA III and Vice City files. The GTAMods Particle (VC) list also contains both names.
Your field values save to session storage while the tab stays open.
