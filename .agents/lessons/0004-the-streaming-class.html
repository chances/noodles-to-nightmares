The Streaming Class

Mission: load models, collision, and scenery before use in main.txt and missions/1_shady_job.txt, so buildings, cars, and characters stop popping or failing. Target: GTA III, Sanny Builder library gta3.

1. What the Class Is

In the GTA III library (gta3.json), Streaming holds 14 static commands. None needs an instance. They fall into four jobs.

ModelsRequestModel(id)0247Requests a new model to load
HasModelLoaded(id)0248Returns true if the model is available for creation
LoadAllModelsNow()038BLoads any requested models synchronously

LoadCollision(level)03F7Loads the level (island) collision

LevelName values from enums.json: Industrial 1, Commercial 2, Suburban 3.

2. The Request, Wait, Use Cycle

The library descriptions imply one cycle: request a model, wait until the matching Has...Loaded check is true, then create the entity. RequestModel only queues the load, and HasModelLoaded reports whether the queue finished. LoadAllModelsNow skips the waiting by loading synchronously. MarkModelAsNoLongerNeeded ends the cycle.

Streaming.RequestModel(#MALE01)
Streaming.LoadAllModelsNow()
// ... create the char ...
Streaming.MarkModelAsNoLongerNeeded(#MALE01)

That exact shape is in utils/characters.txt lines 4 to 7.

The library does not say how long LoadAllModelsNow blocks, or what it does when the game runs out of streaming memory. Neither is tested in this project.

Streaming.LoadModel and Streaming.IsModelLoaded appear in main.txt and the mission file. Neither name is in the library's gta3.json on GitHub master, and neither string appears in the Sanny install's data folder. The library names are RequestModel and HasModelLoaded. Where the project names come from is not established, so the semantics of those lines are unverified.

4. Where the Cycle Can Go Wrong

Three details of the library data matter when streaming misbehaves: the LevelName enum has no value 0, a request that is never followed by MarkModelAsNoLongerNeeded keeps its memory, and Streaming.Switch toggles streaming of "additional models like peds, cars, and maps". The open pop-in bug and its test plan live in building-vehicle-pop-cycle.md.
